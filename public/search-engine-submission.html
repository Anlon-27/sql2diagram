搜索引擎提交说明

站内已经可以提供 sitemap 和 robots，但真正提交到 Google、Bing 或百度站长平台，仍需要你用站点所有者账号手动完成验证与提交。

站内已经准备好的内容

  • sitemap.xml：列出首页、工具页、教程页。
  • robots.txt：允许抓取并指向 sitemap。
  • 每个工具页与教程页都有独立 title、description、canonical 与正文内容。

Google Search Console

  1. 登录 Search Console 并添加属性。
  2. 完成 DNS 或 HTML 文件验证。
  3. 在站点地图入口提交 https://drawlab.top/sitemap.xml。
  4. 后续关注覆盖率、抓取异常和增强结果报告。

Bing Webmaster Tools

  1. 添加站点并完成验证。
  2. 提交 sitemap。
  3. 用 URL Inspection 检查关键工具页和教程页是否已收录。

百度资源平台

  1. 添加站点并完成站点验证。
  2. 提交 sitemap 或使用主动推送。
  3. 优先推送首页、ER 图页、三线表页和教程中心。
如果域名刚上线，先保证页面稳定可访问、内容持续更新，再做站长平台提交，收录会更顺一些。
